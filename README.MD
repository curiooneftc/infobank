## Team Working Rules

1. Verify rules against official FIRST sources.
2. Record important robot changes and test results.
3. Test changes before competition whenever possible.
4. Keep safety and legal compliance as priorities.
5. Use clear filenames and update documentation when designs change.
6. Record the date and source version when updating rules documents.
7. Never assume an inspection pass guarantees compliance after later modifications.

## Suggested Workflow

1. Review the rules and match cheat sheet.
2. Define the scoring strategy.
3. Design and build the robot.
4. Program and test autonomous and teleoperated behavior.
5. Complete the inspection checklist.
6. Prepare using the competition-day guide.
7. Record match results and improve the robot.
