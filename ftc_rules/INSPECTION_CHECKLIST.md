## 1. Official Rules Review

- [ ] Reviewed the latest official Competition Manual.
- [ ] Reviewed all applicable Team Updates.
- [ ] Checked official Q&A clarifications relevant to the robot.
- [ ] Identified the applicable robot construction rules.
- [ ] Confirmed which robot configurations will be used.
- [ ] Prepared any required inspection documentation.

## 2. Robot Dimensions and Configuration

- [ ] Measured the robot in its required starting configuration.
- [ ] Verified starting dimensions against the current manual.
- [ ] Tested all moving and expanding mechanisms.
- [ ] Verified maximum dimensions in every relevant configuration.
- [ ] Confirmed no prohibited component detachment.
- [ ] Confirmed mechanisms remain within permitted expansion limits.
- [ ] Checked that no mechanism catches or damages field elements.

## 3. Mechanical Safety

- [ ] Frame and fasteners are secure.
- [ ] No sharp edges or dangerous protrusions.
- [ ] Wheels, gears, belts, chains, and pulleys are secure.
- [ ] Moving mechanisms operate without binding.
- [ ] Intake and scoring mechanisms are secure.
- [ ] Springs and other stored-energy mechanisms are safe.
- [ ] Robot does not pose an undue hazard to people.
- [ ] Robot is unlikely to damage the field or scoring elements.
- [ ] No loose parts can fall onto the field.

## 4. Electrical and Control Systems

- [ ] All components comply with the current rules.
- [ ] Motors and actuators are legal.
- [ ] Control hub and electronics are mounted securely.
- [ ] Wiring is insulated, secured, and protected from moving parts.
- [ ] Battery and connectors are secure and undamaged.
- [ ] Main power switch is accessible as required.
- [ ] No exposed conductors or short-circuit risks.
- [ ] Sensors are mounted securely.
- [ ] Driver Station connects correctly.
- [ ] Operator Console complies with applicable rules.
- [ ] Emergency stop/disable procedures are understood.

## 5. Software and Operation

- [ ] Correct OpModes are installed.
- [ ] Robot initializes correctly.
- [ ] Autonomous mode behaves as expected.
- [ ] Teleoperated controls work as intended.
- [ ] Motors stop when commanded.
- [ ] No unintended movement occurs during initialization.
- [ ] Transition-period behavior complies with the manual.
- [ ] End-of-match stopping behavior has been tested.
- [ ] Robot remains safe if a sensor or mechanism fails.

## 6. Field Interaction

- [ ] Robot does not deliberately eject scoring elements.
- [ ] Robot does not use prohibited methods to manipulate field elements.
- [ ] Robot does not deliberately damage opponent robots.
- [ ] Robot stays within permitted dimensions.
- [ ] Robot can be safely disabled and retrieved.
- [ ] Preload and starting configuration can be set up correctly.

## 7. Inspection-Day Kit

- [ ] Robot and Operator Console.
- [ ] Batteries and approved charging equipment.
- [ ] Driver Station and cables.
- [ ] Spare fasteners and basic tools.
- [ ] Spare legal components.
- [ ] Robot documentation and configuration notes.
- [ ] Latest official manual available for reference.
