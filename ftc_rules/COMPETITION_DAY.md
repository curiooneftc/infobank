## 1. Before Leaving

### Robot and tools

- [ ] Fully assembled competition robot.
- [ ] Driver Station device and charging cable.
- [ ] Batteries and permitted battery chargers.
- [ ] Spare legal motors, servos, sensors, and cables.
- [ ] Tools and fasteners.
- [ ] Laptop and programming cable.
- [ ] Approved parts for repairs.
- [ ] Inspection checklist.
- [ ] Latest Competition Manual and Team Updates.

### Team essentials

- [ ] Registration and required team documents.
- [ ] Event schedule and venue information.
- [ ] Food and water.
- [ ] Safety glasses and other required protective equipment.
- [ ] Team clothing and identification.
- [ ] Contact information for team members and coaches.

Follow venue restrictions for batteries, chargers, tools, and equipment.

## 2. Arrival and Setup

- [ ] Check in with event staff.
- [ ] Confirm the inspection schedule and match schedule.
- [ ] Set up the pit safely.
- [ ] Keep aisles and emergency access clear.
- [ ] Inspect the robot for transport damage.
- [ ] Check battery condition and charge status.
- [ ] Run the inspection checklist.
- [ ] Complete official inspection.
- [ ] Reinspect after changes when required.
- [ ] Confirm where to queue for matches.

## 4. Before Each Match

- [ ] Confirm match number and alliance color.
- [ ] Check the match schedule for changes.
- [ ] Review the opponent and partner scouting notes.
- [ ] Agree on the AUTO plan.
- [ ] Agree on driver and operator responsibilities.
- [ ] Check robot dimensions and configuration.
- [ ] Check battery charge and connector security.
- [ ] Check wheels, drivetrain, intake, and scoring mechanisms.
- [ ] Confirm the correct OpMode is selected.
- [ ] Confirm preloads and starting setup.
- [ ] Join the queue on time.
- [ ] Listen to field staff and referee instructions.

## 8. Between Matches

- [ ] Check battery charge and rotate batteries as planned.
- [ ] Inspect wheels, fasteners, wiring, and mechanisms.
- [ ] Review errors or unusual robot behavior.
- [ ] Make only necessary repairs or tested changes.
- [ ] Check whether changes require reinspection.
- [ ] Verify the next match time and queue location.
- [ ] Review scouting notes and adjust strategy.
- [ ] Keep the robot and pit organized.

Never install an unverified or potentially illegal modification simply to make a quick repair.

## 9. End of Day

- [ ] Record all match results.
- [ ] Back up code and important configuration files.
- [ ] Record unresolved mechanical and software issues.
- [ ] Inspect the robot for transport damage.
- [ ] Safely disconnect and store batteries.
- [ ] Pack tools and equipment.
- [ ] Check the next day's schedule.
- [ ] Agree on the team's next testing priorities.
